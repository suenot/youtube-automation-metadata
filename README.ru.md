# Video YouTube Prepare

Автоматизированный пайплайн для подготовки метаданных YouTube из готовых видео и блог-статей. Генерирует заголовки, описания, теги, таймкоды и SRT-субтитры на английском и русском языках.

## Что делает

На вход принимает готовый видеофайл и slug блог-статьи, на выходе:

1. **Извлекает аудио** из видео через FFmpeg
2. **Транскрибирует речь** в текст через OpenAI Whisper
3. **Генерирует SRT-субтитры** для загрузки на YouTube
4. **Строит таймкоды глав** сопоставляя заголовки разделов статьи с сегментами транскрипции
5. **Исследует YouTube-теги** из содержимого статьи (заголовки, ключевые фразы, frontmatter-теги)
6. **Генерирует метаданные** (заголовок, описание, теги, таймкоды) на EN и RU — в форматах JSON и TXT

## Требования

- Python 3.9+
- [FFmpeg](https://ffmpeg.org/) установлен и доступен в `PATH`
- [OpenAI Whisper](https://github.com/openai/whisper) (`pip install openai-whisper`)
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) (опционально, для исследования тегов через поиск YouTube)

### Python-зависимости

```bash
pip install openai-whisper
```

## Структура проекта

```
video_youtube_prepare/
├── scripts/
│   ├── prepare_metadata.py   # Основной скрипт пайплайна
│   └── run.sh                # Пакетный запуск для нескольких видео
├── input/                    # Исходные видеофайлы
├── output/                   # Сгенерированные метаданные, SRT-файлы
└── temp/                     # Промежуточные файлы (аудио, JSON субтитров)
```

## Использование

### Одно видео

```bash
python scripts/prepare_metadata.py \
    --video input/my_video.mp4 \
    --slug my-blog-article-slug \
    --output-dir output/my-blog-article-slug \
    --whisper-model base
```

### Пакетная обработка

Отредактируйте `VIDEO_MAP` в `scripts/run.sh`, чтобы задать соответствие видео → slug, затем:

```bash
bash scripts/run.sh
```

### Параметры CLI

| Параметр | Описание | По умолчанию |
|---|---|---|
| `--video` | Путь к входному видеофайлу | *обязательный* |
| `--slug` | Slug блог-статьи (используется для поиска `.en.md` / `.ru.md`) | *обязательный* |
| `--output-dir` | Директория для выходных файлов | *обязательный* |
| `--temp-dir` | Директория для промежуточных файлов | `temp/<slug>` |
| `--whisper-model` | Размер модели Whisper (`tiny`, `base`, `small`, `medium`, `large`) | `base` |
| `--skip-transcribe` | Переиспользовать существующий `subtitles.json` из temp | `false` |

## Выходные файлы

Для каждого видео пайплайн генерирует:

| Файл | Описание |
|---|---|
| `<slug>.srt` | SRT-субтитры, готовые для YouTube |
| `<slug>_metadata.json` | Структурированные EN-метаданные (заголовок, описание, теги, таймкоды) |
| `<slug>_metadata.txt` | Человекочитаемые EN-метаданные для копирования в YouTube Studio |
| `<slug>_ru_metadata.json` | Структурированные RU-метаданные |
| `<slug>_ru_metadata.txt` | Человекочитаемые RU-метаданные |

## Как это работает

### Генерация таймкодов

Вместо фиксированных интервалов инструмент сопоставляет заголовки разделов блог-статьи с сегментами транскрипции Whisper, используя пересечение слов и биграммный скоринг. Это даёт точные маркеры глав, соответствующие реальным переходам между темами в видео.

### Генерация тегов

Теги извлекаются непосредственно из содержимого статьи:
- Заголовки разделов, разбитые по разделителям (скобки, двоеточия, тире)
- Ключевые фразы из описания статьи (осмысленные комбинации из 2-3 слов)
- Frontmatter-теги и их попарные комбинации
- Брендовые теги (`marketmaker`, `marketmaker_cc`) добавляются всегда

### Интеграция с блог-статьями

Инструмент ожидает блог-статьи в формате Markdown с YAML frontmatter по настраиваемому пути (по умолчанию: `../../marketmaker-cc-landing/src/content/blog/`). Статьи должны содержать поля `title`, `description` и `tags`, а также заголовки разделов (`##`) в теле.
